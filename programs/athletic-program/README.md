# Athletic Program

One program with two tracks. Both run the same 3 full-body sessions, so the weekend athlete and the off-season athlete are doing the same method. The athlete track simply adds more volume, harder speed and plyometric options, and two extra conditioning days.

| | Weekend Athlete | Off-Season Athlete |
|---|---|---|
| File | `weekend-athlete-block-1-weeks-1-4.csv` | `off-season-athlete-block-1-weeks-1-4.csv` |
| Sessions/week | 3 lifts + 1 Zone 2 (4 total) | 3 lifts + Zone 2 + Speed/Conditioning (5 total) |
| Session length | ~50-60 min | ~60-70 min |
| Mon | Day 1: Full Body A (Squat + Push) | Day 1: Full Body A (Squat + Push) |
| Tue | Rest | Zone 2, 35-45 min |
| Wed | Day 2: Full Body B (Hinge + Pull) | Day 2: Full Body B (Hinge + Pull) |
| Thu | Rest | Rest |
| Fri | Day 3: Full Body C (Single-leg + Power) | Day 3: Full Body C (Single-leg + Power) |
| Sat | Zone 2 or your sport, 30-40 min | Flying sprints + max-effort intervals |
| Sun | Rest | Rest |

Weekend athletes can run the lifts on any 3 non-consecutive days. The default keeps the weekend free for their game.

## Why it's built this way

- **Full body, 3 days.** Every main pattern (squat, hinge, push, pull, single-leg) gets hit across the week, and missing one day doesn't wipe out a whole muscle group the way a 4-day split does.
- **Supersets.** Push is paired with pull and lunge with Copenhagen, which keeps sessions to about an hour.
- **RIR, not %1RM.** You don't need to test a max. Main lifts never go below RIR 1-2, in line with the ACSM 2026 resistance training position stand (stopping 2-3 reps short works as well as going to failure).
- **Injury-proofing comes built in.** Nordic hamstring curls, Copenhagen planks and calf/Achilles work target the injuries that actually take weekend athletes out: hamstring strains when sprinting, groin strains when changing direction, and calf/Achilles problems.
- **Speed exposure, dosed.** Weekend athletes get build-up runs (70% to 90%) instead of all-out sprints, so the hamstrings are ready when Saturday's game asks for a flat-out effort. Off-season athletes get full acceleration and flying sprints.
- **Trap bar over conventional deadlift.** You get the same hinge stimulus with a lower technical barrier and less lumbar demand.

## Progression (one lever per week, same for both tracks)

1. **Week 1, baseline.** Main lifts at RIR 3.
2. **Week 2, volume.** +1 set on the main and secondary lifts.
3. **Week 3, load.** Add weight and drop a rep. Weekend track peaks at RIR 2, athlete track at RIR 1-2.
4. **Week 4, deload.** About 40-50% less volume at RIR 4-5. Every pattern is still trained.

Power and speed volume stays flat all block. Progress it on quality (height, distance, speed), not on more reps.
