# Marathon — Intermediate — 4-Week Base/Build Block (v2)

**Athlete:** Intermediate marathon runner
**Phase:** Base/build (not taper, not race-specific week)
**Block length:** 4 weeks — Weeks 1–3 progressive overload, Week 4 deload
**Structure held constant across the block:** 4 run sessions, 2 strength sessions, 1 dedicated plyometric session, 1 rest day

All loading is expressed in %1RM, RIR, or % of peak volume — no absolute numbers to plug in. Apply the percentages to whatever the athlete's real numbers are.

This is a first draft — built to be argued with.

---

## The logic (read this before the sessions)

**From an S&C coaching lens:** concurrent training research (Rønnestad & Mujika) is clear — endurance athletes get the strength benefit from *low-volume, high-intensity* lifting, not bodybuilding-style volume. Two sessions a week, near-maximal loads, short-to-moderate rep ranges, full recovery between sets. Strength adaptation runs on **Henneman's size principle** — high-threshold motor units only get recruited under near-maximal load, so the block trends toward higher %1RM and lower reps as the weeks progress (classic step-loading), not more volume.

**From a physio/sports doctor lens:** the plyometric session is quarantined to one day, done fresh, no hard run within 24h either side. It progresses in *volume and drill complexity* across the block — depth jumps don't appear until Week 3, once the athlete has three weeks of squat/hinge loading under them. Purpose is tendon stiffness and stretch-shortening cycle efficiency (Saunders et al.; Ramírez-Campillo meta-analyses), not "explosiveness for its own sake."

**Aerobic side runs on Seiler's polarized model:** ~80% of running volume stays in Zone 2 (60–70% max HR), ~20% sits at threshold/VO2max. That ratio holds every week, including the deload — the deload cuts *volume*, not the polarization.

**Why Week 4 deloads, and why volume drops before intensity:** this follows standard periodization practice (Bompa; Mujika & Padilla on tapering) — systemic fatigue accumulates fastest from volume, so volume gets cut hardest (~45–50%) while intensity is preserved or only trimmed slightly. That protects neuromuscular sharpness and lets adaptation actually consolidate (supercompensation) before the next block loads back up. Plyo gets the deepest cut of all — it's the highest neuromuscular/tendon stress per rep and the least forgiving if pushed into fatigue.

**SAID principle underwrites the whole block:** every session has a specific job, and that job doesn't change week to week — only its dial (%1RM, volume, drill complexity) moves.

## Weekly skeleton (fixed across all 4 weeks)

| Day | Session |
|---|---|
| Mon | Rest / mobility |
| Tue | **Strength A** — Lower-body max strength |
| Wed | **Threshold / VO2max run** |
| Thu | Easy run + **Strength B** — Upper body & core |
| Fri | **Dedicated plyometric session** |
| Sat | Easy run (short shakeout) |
| Sun | **Long run** |

---

## Micro view — the block, day by day

| Day | Week 1 | Week 2 | Week 3 (Peak) | Week 4 (Deload) |
|---|---|---|---|---|
| **Mon** | Rest | Rest | Rest | Rest |
| **Tue** — Strength A | Main lift 4×5 @ 75% 1RM · accessories @ RIR 3 | Main lift 4×4 @ 80% 1RM · accessories @ RIR 2 | Main lift 4×3 @ 85% 1RM · accessories @ RIR 1–2 | Main lift 3×3 @ 65% 1RM · accessories @ RIR 4, light |
| **Wed** — Threshold | 4×6 min @ threshold pace (24 min time-in-zone) | 5×6 min (30 min TIZ) | 6×6 min (36 min TIZ) — peak | 3×5 min (15 min TIZ, ~40% of peak volume, same pace) |
| **Thu** — Easy run + Strength B | 40 min Z2 run · Strength B @ RPE 6–7 | 40 min Z2 · RPE 7 | 40 min Z2 · RPE 7–8 | 25 min Z2 · RPE 5, light |
| **Fri** — Plyometric | 70% of peak volume — pogo, CMJ, bounding only, no depth jumps | 85% of peak volume — depth jumps introduced, low set count | 100% volume — full session incl. depth jumps — peak | 50% of peak volume — pogo + CMJ only, submaximal effort |
| **Sat** — Easy run | 35 min Z2 | 35 min Z2 | 35 min Z2 | 25 min Z2 |
| **Sun** — Long run | 80% of peak long-run duration | 90% of peak | 100% — peak long run | 55% of peak |

*"Peak" = Week 3 in every row. Set Week 3 to whatever duration/volume is appropriate for the athlete, then back-calculate Weeks 1, 2, and 4 from that number.*

## Session content (exercises stay constant — only the dials above change)

### Strength A — Lower-Body Max Strength (Tue)
1. Back Squat or Trap Bar Deadlift — sets/%/reps per week table above, 3 min rest
2. Single-Leg RDL — 3×6/leg, 90 s rest, load scales with weekly RIR target
3. Bulgarian Split Squat — 3×5/leg, 2 min rest, load scales with weekly RIR target
4. Straight-Leg Calf Raise — 4×8, slow eccentric, heavy relative to the week's RIR target
5. Copenhagen Plank — 3×30 s/side, constant across the block (injury-prevention accessory, not a loading variable)

### Threshold / VO2max Run (Wed)
- 15 min warm-up, Zone 2
- Main set per week table above, 90 s jog recovery between reps, threshold pace held constant across weeks (comfortably-hard, sustainable ~60 min race effort) — only *volume* moves
- 15 min cool-down, Zone 2

### Easy Run + Strength B — Upper Body & Core (Thu)
**Run:** Zone 2 (60–70% max HR), conversational, duration per week table above.

**Strength B:**
1. Pull-up or Lat Pulldown — 3×6–8
2. DB Bench Press or Push-up — 3×8
3. Single-Arm DB Row — 3×8/side
4. Pallof Press — 3×10/side
5. Dead Bug — 3×10

Load/effort scales with the week's RPE target; exercise selection stays fixed.

### Dedicated Plyometric Session (Fri)
Fresh legs only, no hard run within 24h either side.

Warm-up: 10 min dynamic + 2×10 pogo hops + 2×10 ankle skips

1. Pogo Jumps — present every week, sets scale with weekly volume %
2. Countermovement Jumps — present every week, sets scale with weekly volume %
3. Bounding — present every week, reps scale with weekly volume %
4. Single-Leg Hop for Distance — present every week, sets scale with weekly volume %
5. Low Box Depth Jumps (~20–30 cm) — **Week 3 only**, added once the athlete has three weeks of squat/hinge loading under them; dropped entirely in the Week 4 deload

### Easy Run (Sat)
Zone 2, duration per week table above. Shakeout, primes legs for Sunday.

### Long Run (Sun)
Zone 2, duration per week table above (the block's primary aerobic-volume driver). Later blocks (not this one) can add a marathon-pace finish segment for specificity — not yet, in a base block.

## Open questions to tune this
- Set Week 3's long-run duration and threshold pace — everything else in the block scales off those two numbers.
- 1RM (or a working top set) for the Strength A main lift, so the %1RM column has something to attach to.
- Preferred long-run day — Sunday assumed.
- Any current niggles/injury history the physio lens needs to account for before Week 3's depth jumps get greenlit.
